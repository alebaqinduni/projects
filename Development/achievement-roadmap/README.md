# GitHub Achievement Roadmap

This roadmap is designed to help build **legitimate GitHub activity**. It does not promise a fixed number of achievements: GitHub awards achievements only when its qualifying conditions are actually met.

## Rules

- Do real work; never spam issues, pull requests, comments, or commits.
- Make changes that are useful to the project.
- Use meaningful commit messages.
- Keep your GitHub account email configured correctly for contributions.
- Prefer collaboration and open-source contributions over activity manufactured only for a badge.
- Check your profile after qualifying activity; some achievements may not appear instantly.

## Open-source contribution ladder

1. Find a project you genuinely use.
2. Read its contribution guidelines.
3. Start with documentation or a small bug fix.
4. Open a useful issue when appropriate.
5. Submit a meaningful pull request.
6. Respond to maintainer feedback.
7. Review other contributors' work when you have enough context.
8. Participate constructively in project discussions.
9. Continue contributing to projects you actually care about.

## Achievement tracking

Keep a personal record of:

- qualifying pull requests
- meaningful reviews
- useful issue participation
- discussion participation
- releases
- open-source contributions
- any achievement GitHub explicitly awards

**Do not treat this list as a guarantee of achievements.** GitHub can change achievement criteria, and many achievements depend on actions outside this repository.
