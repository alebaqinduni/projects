# Development

This folder is for legitimate GitHub development work and a badge-earning roadmap.

## Important: badges are earned by GitHub activity

Repository files alone cannot legitimately grant 100+ GitHub profile achievements. GitHub achievements are tied to qualifying actions and milestones (for example, participating in pull requests, reviews, issues, discussions, or other supported activities), and creating dummy files or automated activity does not guarantee achievements.

Instead, use this folder for real work that can naturally create qualifying activity:

- Build and improve genuine projects.
- Open useful pull requests and contribute to projects you actually use.
- Review other contributors' pull requests when you can provide substantive feedback.
- Participate constructively in GitHub Discussions and issues.
- Maintain documentation, tests, accessibility fixes, bug fixes, and features.
- Collaborate with other developers on real changes.
- Keep commits meaningful and tied to actual development.
