# Password Strength Checker

A local browser tool that gives a simple password-strength estimate without sending the password to a server.

## Goals

- Keep password input local to the browser.
- Provide understandable feedback.
- Make the interface keyboard accessible.
- Keep the implementation dependency-free.

## Development tasks

- Add automated tests for scoring rules.
- Add accessibility checks.
- Document the scoring model.
- Improve feedback for weak passwords without exposing entered passwords.

> This project is educational and is not a password-security audit service.
