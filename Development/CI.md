# Continuous Integration Plan

The Development projects should use CI to verify real changes before merging.

## Planned checks

- Run automated tests.
- Check formatting and linting where the language supports it.
- Verify documentation examples when practical.
- Keep dependencies current and review security alerts.
- Do not add workflows whose only purpose is to generate artificial contribution activity.

## Quality gate

A change should be merged because it improves the project, passes validation, and is understandable to another contributor—not because it increases a profile counter.
