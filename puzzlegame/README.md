# Puzzle Game

A standalone sliding puzzle (15-puzzle) built with plain HTML, CSS, and JavaScript.

## Run locally

1. Open `/home/runner/work/projects/projects/puzzlegame/index.html` in any modern browser.
2. Click **New Game** to shuffle and start.

## How to play

- Click a numbered tile next to the empty space to move it.
- Arrange the tiles from 1 to 15 in order.
- Use **Restart** to reset to the current game's initial shuffled layout.
